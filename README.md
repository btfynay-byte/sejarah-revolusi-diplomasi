        <h1>Revolusi <em>Fisik</em></h1>

      <div class="article-wrap">
        <div class="article-topline"><span>PERISTIWA SEJARAH</span><span>MEDAN, SUMATRA UTARA • 1945–1947</span></div>
        <h2>Pertempuran <em>Medan Area</em></h2>
        <p class="article-intro">Pertempuran Medan Area merupakan salah satu perlawanan rakyat Indonesia terhadap kedatangan Sekutu yang diboncengi NICA di Sumatra Utara setelah Indonesia memproklamasikan kemerdekaannya.</p>
        <p><a class="text-link" href="#ags">Lanjutkan ke perjuangan AGS di Sipirok ↗</a></p>
        <figure class="wide-figure"><img src="https://upload.wikimedia.org/wikipedia/commons/thumb/1/1c/Flag_of_Indonesia.svg/1280px-Flag_of_Indonesia.svg.png" alt="Bendera Indonesia"><figcaption>Merah putih menjadi lambang kedaulatan Republik Indonesia. Ganti atau tambahkan foto arsip Pertempuran Medan Area yang terverifikasi untuk dokumentasi peristiwa.</figcaption></figure>
        <div class="article-grid">
          <aside class="fact-card"><p class="eyebrow">RINGKASAN PERISTIWA</p><div><small>Waktu</small><b>Oktober 1945 – 1947</b></div><div><small>Lokasi</small><b>Medan dan sekitarnya, Sumatra Utara</b></div><div><small>Pihak yang terlibat</small><b>Pejuang Republik, Sekutu, dan NICA</b></div></aside>
          <div class="article-body">
            <h3>Latar belakang</h3>
            <p>Setelah Jepang menyerah pada Agustus 1945, pasukan Sekutu datang ke Indonesia untuk menerima penyerahan Jepang, membebaskan tawanan perang, dan melucuti tentara Jepang. Di Sumatra Utara, kedatangan pasukan Sekutu pada Oktober 1945 disertai unsur Netherlands Indies Civil Administration (NICA), yang bertujuan memulihkan pemerintahan kolonial Belanda.</p>
            <p>Kehadiran NICA menimbulkan kecurigaan dan penolakan rakyat karena dianggap mengancam kemerdekaan Indonesia. Ketegangan kemudian berkembang menjadi bentrokan bersenjata.</p>
            <h3>Awal terjadinya pertempuran</h3>
            <p>Salah satu pemicu ketegangan adalah insiden di sebuah hotel di Medan pada 13 Oktober 1945. Seorang anggota Sekutu dikabarkan merampas dan menginjak lencana Merah Putih yang dikenakan seorang pemuda. Insiden tersebut memicu kemarahan para pemuda dan berkembang menjadi bentrokan dengan pasukan Sekutu serta NICA.</p>
            <h3>Kronologi penting</h3>
            <div class="timeline">
              <div class="timeline-item"><b>9 Oktober 1945</b><p>Pasukan Sekutu di bawah komando Brigadir Jenderal T. E. D. Kelly tiba di Medan bersama unsur NICA.</p></div>
              <div class="timeline-item"><b>13 Oktober 1945</b><p>Insiden lencana Merah Putih memicu bentrokan antara pemuda Indonesia dan pasukan Sekutu/NICA.</p></div>
              <div class="timeline-item"><b>1 Desember 1945</b><p>Sekutu memasang papan bertuliskan “Fixed Boundaries Medan Area” di sejumlah titik. Istilah Medan Area kemudian dikenal luas untuk menyebut wilayah konflik tersebut.</p></div>
              <div class="timeline-item"><b>10 Desember 1945</b><p>Sekutu melancarkan serangan besar ke wilayah Medan dan sekitarnya. Perlawanan rakyat terus berlangsung.</p></div>
              <div class="timeline-item"><b>1946–1947</b><p>Pertempuran dan perlawanan berlanjut di berbagai wilayah Sumatra Timur. Pasukan Republik melakukan konsolidasi dan strategi gerilya.</p></div>
            </div>
            <h3>Tokoh dan kekuatan perjuangan</h3>
            <p>Perlawanan melibatkan para pemuda, laskar rakyat, Tentara Keamanan Rakyat (TKR) yang kemudian berkembang menjadi TNI, serta berbagai organisasi perjuangan di Sumatra Utara. Salah satu tokoh yang dikenal dalam perjuangan di kawasan ini adalah Achmad Tahir.</p>
            <h3>Dampak dan makna perjuangan</h3>
            <p>Pertempuran Medan Area menunjukkan bahwa rakyat Indonesia di berbagai daerah tidak menerima kembalinya kekuasaan kolonial. Peristiwa ini memperkuat semangat mempertahankan kemerdekaan dan menjadi bagian dari rangkaian revolusi fisik di Indonesia.</p>
          </div>
        </div>

        <div class="ags-section" id="ags">
          <div class="ags-kicker"><span>LANJUTAN PERJUANGAN DI SUMATERA UTARA</span><span>1949–1950</span></div>
          <h2>Perjuangan Berlanjut: <em>Angkatan Gerilya Sipirok</em></h2>
          <p class="article-intro">Perlawanan mempertahankan kemerdekaan tidak hanya berlangsung di Medan. Di wilayah Tapanuli Selatan, para pejuang dan masyarakat Sipirok juga membentuk kekuatan gerilya untuk menghadang gerak pasukan Belanda pada masa Agresi Militer Belanda II.</p>
          <div class="ags-highlight">
            <div><small>DIBENTUK</small><b>3 Januari 1949</b></div>
            <div><small>PEMIMPIN</small><b>Sahala Muda Pakpahan</b></div>
            <div><small>WILAYAH</small><b>Sipirok, Tapanuli Selatan</b></div>
          </div>
          <div class="ags-content-grid">
            <div class="ags-story">
              <h3>Latar belakang pembentukan</h3>
              <p>Angkatan Gerilya Sipirok (AGS) dibentuk untuk menghadapi ancaman Agresi Militer Belanda II dan menghambat pergerakan pasukan Belanda dari Sumatera Timur menuju wilayah Tapanuli. AGS melibatkan unsur Tentara Keamanan Rakyat (TKR), laskar pejuang, pemuda, tokoh masyarakat, dan warga setempat.</p>
              <p>Menurut penelitian Cipto Duwi Priyono, pasukan ini memiliki keterbatasan persenjataan. Para anggotanya menggunakan senjata yang tersedia, termasuk senapan locok dan senjata tradisional.</p>
              <h3>Perlawanan di Bukit Simago-Mago</h3>
              <p>Salah satu peristiwa penting terjadi pada 23 Mei 1949 di kawasan Bukit Simago-Mago. Dalam penelitian tersebut, seorang mantan anggota AGS menceritakan adanya upaya penghadangan konvoi Belanda yang melintas dari arah Pal-XI. Serangan diarahkan kepada kendaraan lapis baja yang menurut kesaksian itu membawa Jenderal Simon Spoor. Pasukan AGS kemudian mundur setelah mendapat perlawanan dan serangan udara.</p>
              <p><strong>Catatan kehati-hatian:</strong> artikel tersebut memuat kesaksian bahwa kendaraan lapis baja hancur dan kabar mengenai tewasnya Simon Spoor, tetapi kesaksian yang dikutip tidak memastikan jumlah korban maupun memastikan bahwa Spoor tewas. Karena itu, museum ini tidak menyajikannya sebagai fakta yang sudah terkonfirmasi.</p>
              <h3>Nasib Sahala Muda Pakpahan</h3>
              <p>Penelitian yang sama menyebut Sahala Muda Pakpahan ditangkap di kawasan Sabatolang pada Agustus 1949. Jenazahnya kemudian ditemukan pada 20 Agustus 1949 di Huta Maragordong, sekitar Jembatan Aek Hambiri. Peristiwa ini menjadi bagian dari kisah pengorbanan para pejuang dan masyarakat Sipirok.</p>
              <h3>Makna perjuangan AGS</h3>
              <p>Perjuangan AGS memperlihatkan bahwa pertahanan kemerdekaan merupakan usaha bersama yang melibatkan masyarakat daerah. Perlawanan di Sipirok juga memiliki arti strategis karena berupaya menghambat gerak pasukan Belanda antara Sumatera Timur dan wilayah Tapanuli.</p>
            </div>
            <aside class="ags-side">
              <p class="eyebrow">GARIS WAKTU AGS</p>
              <div class="timeline ags-timeline">
                <div class="timeline-item"><b>3 Januari 1949</b><p>AGS dilantik dan dipimpin Sahala Muda Pakpahan.</p></div>

                <div class="timeline-item"><b>1949–1950</b><p>Perjuangan AGS dikenang sebagai bagian dari perlawanan mempertahankan kemerdekaan di Tapanuli Selatan.</p></div>
              </div>
              <div class="ags-note"><b>Hubungannya dengan Medan Area</b><p>Medan Area (1945–1947) dan perjuangan AGS (1949–1950) bukan satu pertempuran yang sama. Keduanya merupakan bagian dari rangkaian perjuangan mempertahankan kemerdekaan di Sumatera Utara pada masa yang berbeda.</p></div>

          <div class="dip-number">01</div><p class="eyebrow">15 NOVEMBER 1946 • LINGGARJATI, JAWA BARAT</p><h2>Perundingan <em>Linggarjati</em></h2>
          <div class="dip-layout"><div><h3>Latar belakang</h3><p>Konflik antara Indonesia dan Belanda mendorong kedua pihak mencari penyelesaian melalui perundingan. Perundingan berlangsung di Linggarjati, dekat Cirebon, dan naskah persetujuannya diparaf pada November 1946.</p><h3>Tokoh</h3><p>Delegasi Indonesia dipimpin Sutan Sjahrir, sedangkan delegasi Belanda dipimpin Wim Schermerhorn. Lord Killearn dari Inggris membantu proses perundingan.</p><h3>Isi pokok persetujuan</h3><ul><li>Belanda mengakui secara de facto kekuasaan Republik Indonesia atas Jawa, Madura, dan Sumatra.</li><li>Indonesia dan Belanda sepakat membentuk Republik Indonesia Serikat (RIS).</li><li>RIS dan Belanda direncanakan tergabung dalam Uni Indonesia-Belanda.</li></ul><h3>Dampak</h3><p>Persetujuan ini memberi pengakuan de facto terhadap wilayah Republik, tetapi perbedaan penafsiran dan pelaksanaan kesepakatan menimbulkan ketegangan baru.</p></div><img src="https://placehold.co/760x900/d8d0c2/4a4035?text=Dokumentasi+Linggarjati" alt="Dokumentasi Perundingan Linggarjati"></div>
        </article>

        <article class="dip-panel" id="ktn">
          <div class="dip-number">02</div><p class="eyebrow">1947 • MEDIASI PERSERIKATAN BANGSA-BANGSA</p><h2>Komisi <em>Tiga Negara (KTN)</em></h2>
          <div class="dip-layout"><div><h3>Latar belakang</h3><p>Setelah Agresi Militer Belanda I pada 21 Juli 1947, konflik Indonesia-Belanda mendapat perhatian Dewan Keamanan PBB. PBB kemudian membentuk komisi untuk membantu penyelesaian konflik.</p><h3>Anggota KTN</h3><ul><li>Australia, dipilih Indonesia, diwakili Richard C. Kirby.</li><li>Belgia, dipilih Belanda, diwakili Paul van Zeeland.</li><li>Amerika Serikat, dipilih sebagai pihak ketiga, diwakili Frank Porter Graham.</li></ul><h3>Tugas dan peran</h3><p>KTN membantu mengawasi gencatan senjata dan memfasilitasi perundingan antara Indonesia dan Belanda. Komisi ini berperan dalam proses yang kemudian mengarah pada Perjanjian Renville.</p><h3>Dampak</h3><p>Persoalan Indonesia-Belanda semakin mendapat perhatian internasional dan penyelesaian konflik memperoleh jalur mediasi PBB.</p></div><img src="https://placehold.co/760x900/c9c1b3/4a4035?text=Dokumentasi+KTN" alt="Dokumentasi Komisi Tiga Negara"></div>
        </article>

        <article class="dip-panel" id="renville">
          <div class="dip-number">03</div><p class="eyebrow">17 JANUARI 1948 • KAPAL USS RENVILLE</p><h2>Perjanjian <em>Renville</em></h2>
          <div class="dip-layout"><div><h3>Latar belakang</h3><p>Perundingan dilakukan setelah Agresi Militer Belanda I dengan bantuan mediasi KTN. Perundingan berlangsung di atas kapal perang Amerika Serikat, USS Renville, yang berlabuh di Tanjung Priok, Jakarta.</p><h3>Tokoh</h3><p>Delegasi Indonesia dipimpin Amir Sjarifuddin, sedangkan delegasi Belanda dipimpin R. Abdulkadir Widjojoatmodjo. KTN bertindak sebagai mediator.</p><h3>Isi pokok</h3><ul><li>Disepakati prinsip penghentian tembak-menembak dan garis demarkasi.</li><li>Garis demarkasi yang dikenal sebagai Garis Van Mook membatasi wilayah yang dikuasai kedua pihak.</li><li>Pasukan Republik di wilayah yang berada di belakang garis Belanda harus ditarik, termasuk Divisi Siliwangi dari Jawa Barat.</li></ul><h3>Dampak</h3><p>Wilayah Republik semakin sempit dan kondisi politik serta militer Indonesia menjadi lebih sulit. Perjanjian ini menimbulkan kritik di dalam negeri.</p></div><img src="https://placehold.co/760x900/bbb3a5/4a4035?text=Kapal+USS+Renville" alt="Dokumentasi kapal USS Renville"></div>
        </article>

        <article class="dip-panel" id="roem">
          <div class="dip-number">04</div><p class="eyebrow">7 MEI 1949 • JAKARTA</p><h2>Perjanjian <em>Roem-Royen</em></h2>
          <div class="dip-layout"><div><h3>Latar belakang</h3><p>Agresi Militer Belanda II pada 19 Desember 1948 menyebabkan Yogyakarta diduduki dan sejumlah pemimpin Republik ditangkap. Tekanan internasional, termasuk dari PBB dan Amerika Serikat, mendorong dimulainya perundingan kembali.</p><h3>Tokoh</h3><p>Delegasi Indonesia dipimpin Mohammad Roem dan delegasi Belanda dipimpin Herman van Roijen. UNCI membantu proses perundingan.</p><h3>Pokok kesepakatan</h3><ul><li>Pemerintah Republik Indonesia bersedia menghentikan perang gerilya.</li><li>Belanda menyetujui pengembalian pemerintahan Republik ke Yogyakarta.</li><li>Belanda akan membebaskan para pemimpin Republik yang ditawan.</li><li>Kedua pihak sepakat mengikuti Konferensi Meja Bundar.</li></ul><h3>Dampak</h3><p>Perjanjian ini membuka jalan bagi pemulihan pemerintahan Republik di Yogyakarta dan pelaksanaan Konferensi Meja Bundar.</p></div><img src="https://placehold.co/760x900/d8d0c2/4a4035?text=Dokumentasi+Roem+Royen" alt="Dokumentasi Perjanjian Roem-Royen"></div>

const pages = [...document.querySelectorAll('.page')];
const navLinks = [...document.querySelectorAll('.nav-link')];
const nav = document.getElementById('mainNav');
const menuToggle = document.getElementById('menuToggle');
const music = document.getElementById('backgroundMusic');
const soundBtn = document.getElementById('soundBtn');
const soundLabel = document.getElementById('soundLabel');
let musicOn = false;

function showPage() {
  const id = (location.hash || '#beranda').slice(1);
  const requested = document.getElementById(id);
  const target = pages.find(page => page.id === id) || requested?.closest('.page') || pages[0];

  pages.forEach(page => page.classList.toggle('active-page', page === target));
  navLinks.forEach(link => link.classList.toggle('active', link.getAttribute('href') === `#${target.id}`));

  nav.classList.remove('open');

  if (requested && requested !== target) {
    requestAnimationFrame(() => requested.scrollIntoView({behavior: 'smooth', block: 'start'}));
  } else {
    window.scrollTo({top: 0, behavior: 'smooth'});
  }
}

window.addEventListener('hashchange', showPage);
window.addEventListener('DOMContentLoaded', showPage);

menuToggle.addEventListener('click', () => nav.classList.toggle('open'));

soundBtn.addEventListener('click', async () => {
  if (!musicOn) {
    try {
      await music.play();
      musicOn = true;
      soundLabel.textContent = 'Musik: ON';
      soundBtn.setAttribute('aria-label', 'Matikan musik');
    } catch (error) {
      soundLabel.textContent = 'Tambahkan musik';
    }
  } else {
    music.pause();
    musicOn = false;
    soundLabel.textContent = 'Musik: OFF';
    soundBtn.setAttribute('aria-label', 'Aktifkan musik');
  }
});

// Navigasi tujuh bagian diplomasi
const panels = [...document.querySelectorAll('.dip-panel')];
const tabs = [...document.querySelectorAll('.dip-tab')];
let dipIndex = 0;

const dipCount = document.getElementById('dipCount');
const prevDip = document.getElementById('prevDip');
const nextDip = document.getElementById('nextDip');

function setDip(index) {
  dipIndex = Math.max(0, Math.min(index, panels.length - 1));

  panels.forEach((panel, i) => panel.classList.toggle('active', i === dipIndex));
  tabs.forEach((tab, i) => tab.classList.toggle('active', i === dipIndex));

  dipCount.textContent = `${String(dipIndex + 1).padStart(2, '0')} / ${String(panels.length).padStart(2, '0')}`;

  prevDip.disabled = dipIndex === 0;
  nextDip.disabled = dipIndex === panels.length - 1;
}

tabs.forEach((tab, i) => tab.addEventListener('click', () => setDip(i)));
prevDip.addEventListener('click', () => setDip(dipIndex - 1));
nextDip.addEventListener('click', () => setDip(dipIndex + 1));

const lightbox = document.getElementById('lightbox');
const lightboxImage = document.getElementById('lightboxImage');

document.querySelectorAll('.gallery-grid img, .dip-layout img').forEach(img => {
  img.addEventListener('click', () => {
    lightboxImage.src = img.src;
    lightboxImage.alt = img.alt;
    lightbox.classList.add('open');
  });
});

function closeLightbox() {
  lightbox.classList.remove('open');
}

document.getElementById('closeLightbox').addEventListener('click', closeLightbox);

lightbox.addEventListener('click', e => {
  if (e.target === lightbox) closeLightbox();
});

document.addEventListener('keydown', e => {
  if (e.key === 'Escape') closeLightbox();
});
